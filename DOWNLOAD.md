# Download Codex Gauge

Use this link:

[Download Codex Gauge for macOS](https://github.com/jakobdsavage-afk/CodexGauge/releases/latest/download/CodexGauge.zip)

Then:

1. Open `CodexGauge.zip`.
2. Drag `CodexGauge.app` into Applications.
3. Open `CodexGauge.app`.

If macOS blocks it the first time:

1. Right-click `CodexGauge.app`.
2. Click `Open`.
3. Click `Open` again.

After that, Codex Gauge updates itself automatically.
